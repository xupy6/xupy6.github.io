# 给个人主页加一个能长期写的 Notes

今天把个人主页的 Notes 页面整理了一下。这个功能不复杂，就是从 `blogs/` 目录读取 Markdown，然后在页面上列出来。

但我觉得它挺重要。项目做完之后，如果只剩一个仓库链接，很多过程会丢掉。比如为什么这里用了 LangGraph，为什么 RAG 默认关闭，为什么某个 UI 动效后来删掉了。这些东西不一定适合写进 README，但很适合写成短笔记。

现在的方式很轻：

- 写一个 Markdown 文件。
- 文件名带日期。
- front matter 写标题、摘要和标签。
- 推送到 GitHub 后页面自动读取。

这样以后不用每次改页面结构，也不用开一个很重的博客系统。对我来说够用了。

后面如果继续完善，可能会加标签筛选和搜索。但先不急。博客功能最重要的不是功能多，而是真的能写下去。
