# 第一篇开发笔记

这个页面用于记录 Agent、LLM 应用、AI4S、全栈工程和可交互式 AI 产品相关的开发笔记。

以后写博客很简单：

- 在仓库的 `blogs/` 目录中新建一个 `.md` 文件。
- 文件名建议使用 `YYYY-MM-DD-title.md`。
- 推送到 GitHub 后，`blog.html` 会自动读取这个目录并展示文章。

## Markdown 格式

每篇文章开头可以写 front matter：

```markdown
---
title: 文章标题
date: 2026-08-28
summary: 一句话摘要
tags: Agent, LLM
---
```

正文支持标题、列表、引用、代码块、链接和加粗文本。
